# otgo artwork

The otgo mark is a small animal peeking out of a tunnel. Its rounded portal and
face are original SVG geometry; it contains no Go gopher or OpenTunnel artwork.
Use it on a dark background with mint (`#91e7ca`) and warm white (`#f0f3eb`).

The [SVG source](../internal/authproxy/ui/mark.svg) is covered by the repository’s
[MIT license](../LICENSE). The CLI embeds it directly into its pages. It needs
no image server, network request or runtime dependency.

## GitHub sign-in icon

The sign-in button uses GitHub’s own mark to identify the provider. It is separate
from the otgo logo. The icon comes from
[Primer Octicons, revision 97825f832c98f817867f770d084c08e3edc6f78c](https://github.com/primer/octicons/blob/97825f832c98f817867f770d084c08e3edc6f78c/icons/mark-github-24.svg).
Its [MIT license](../internal/authproxy/ui/octicons-LICENSE.txt) is included in the
source and embedded binary. GitHub’s marks remain GitHub’s trademarks; see its
[logo guidance](https://brand.github.com/foundations/logo).
